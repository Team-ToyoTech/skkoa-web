SKKOA; LTW 문서

SKKOA; LTW는 Starter Kit with Korean Oriented Architecture; Language to Write 의 약자입니다. 한국어 친화적 문법과 직관적인 구조를 갖춘 교육용 프로그래밍 언어입니다.

문법과 기능 설명은 각각 독립 문서로 분리되어 있습니다. 필요한 문서를 바로 열어 읽을 수 있습니다.

문법 문서 기본 구조, 자료형, 변수, 조건문, 반복문, 함수, 배열, 문자열, 포인터 문법을 정리합니다. 기능 문서 현재 지원 기능, 표준 라이브러리, 자료구조, 컴파일러 명령과 제한 사항을 정리합니다.

소개

SKKOA; LTW는 Starter Kit with Korean Oriented Architecture; Language to Write를 뜻합니다. 한국어 키워드로 코드를 읽고 쓰는 언어이며, 영어 문법을 먼저 외우기보다 프로그램이 어떤 순서로 움직이는지 익히는 데 초점을 둡니다. 

시작
    출력 "처음 만드는 프로그램"
끝

위 코드는 화면에 문장을 보여 줍니다.

시작하기

처음에는 아래 모양만 기억하면 됩니다.

시작
    출력 "안녕하세요, SKKOA; LTW!"
끝

SKKOA; LTW 코드는 .koa 파일에 저장합니다. 설치가 끝나면 터미널에서 아래처럼 실행할 수 있습니다. 

skkoa hello.koa

운영체제별 설치 파일은 다운로드 페이지에서 받을 수 있습니다.
