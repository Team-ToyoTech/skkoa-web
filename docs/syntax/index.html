문법 문서

SKKOA; LTW 코드는 한국어 키워드와 간단한 블록 구조로 작성합니다. 프로그램은 보통 시작과 끝 사이에 실행할 코드를 둡니다. 

시작
    출력 "Hello"
끝

줄마다 하나씩 쓰기

한 줄에 하나의 일을 쓰면 읽기 쉽습니다.

변수 age: 정수 = 20
출력 age

주석

주석은 컴퓨터가 실행하지 않는 설명입니다.

# 이름을 출력합니다
출력 "SKKOA; LTW"

다른 파일 가져오기

가져오기 "stack.koa"
가져오기 "queue.koa"

가져온 뒤에는 그 파일 안에 있는 구조체와 함수를 바로 사용할 수 있습니다.

자료형

자료형은 값의 종류입니다.

자료형 담는 값
정수 1, 2, 100 같은 숫자
실수 1.5, 3.14 같은 소수
논리 참 또는 거짓
문자 'A' 같은 한 글자
문자열 "안녕하세요" 같은 글
없음 함수가 돌려주는 값이 없을 때
포인터<정수> 주소를 다룰 때 사용하는 값 
시작
    변수 age: 정수 = 20
    변수 height: 실수 = 170.5
    변수 passed: 논리 = 참
    변수 name: 문자열 = "SKKOA; LTW"

    출력 age
    출력 height
    출력 passed
    출력 name
끝

변수와 상수

변수는 값을 담는 이름입니다.

변수 x: 정수 = 10

값 바꾸기

시작
    변수 score: 정수 = 70
    score = score + 10
    출력 score
끝

입력으로 값 넣기

시작
    변수 age: 정수
    입력 age
    출력 age
끝

정수, 논리, 실수, 문자, 포인터 입력은 공백이나 줄바꿈으로 구분해서 여러 값을 한 번에 넣을 수 있습니다. 문자열 입력은 다음 줄 전체를 읽기 때문에 띄어쓰기가 그대로 유지됩니다. 

시작
    변수 left: 정수
    변수 right: 정수
    변수 name: 문자열

    입력 left
    입력 right
    입력 name

    출력 left + right
    출력 name
끝

배열

배열은 같은 종류의 값을 여러 개 담는 상자입니다.

    numbers[0] = 10
    numbers[1] = 20
    numbers[2] = 30

    출력 numbers[0] + numbers[1] + numbers[2]
끝

시작

    출력 numbers[0]
끝

포인터

포인터는 어떤 값이 있는 위치를 담습니다. 변수, 조건문, 반복문, 함수, 배열을 먼저 익힌 뒤 읽어도 됩니다. 

시작
    변수 x: 정수 = 10
    변수 p: 포인터<정수> = 주소(x)

    출력 값(p)
끝

값 바꾸기

시작
    변수 x: 정수 = 10
    변수 p: 포인터<정수> = 주소(x)

    값(p) = 25
    출력 x
끝
