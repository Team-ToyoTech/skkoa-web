웹에서 열기

IDE 기능

고급 코드 편집

Scintilla 기반 탭 편집, 줄 번호, 현재 줄 강조, 한글 키워드 구문 강조, 찾기/바꾸기를 제공합니다.

자동완성과 포맷팅

Ctrl+Space 추천어, SKKOA 키워드/표준 함수 후보, 스니펫 삽입, Enter 자동 들여쓰기를 지원합니다.

진단과 Problems

편집 중 `skkoa.exe --check`를 디바운스 실행하고, 오류 밑줄과 Problems 패널 이동을 제공합니다.

컴파일과 실행

내장 컴파일러와 표준 모듈을 앱 폴더에서 찾고, Output/Console 패널에서 빌드 로그와 입력을 관리합니다.

단계별 디버깅

SKKOA 언어 전용 실행기로 브레이크포인트, Step Into, Continue, Watch, Call Stack을 제공합니다.

Windows 설치 통합

시작 메뉴, 바탕화면 바로가기, `.koa`와 `.skkoaproj` 파일 연결, 제거 프로그램 등록을 지원합니다.

시스템 요구 사항

  • Windows 10 또는 Windows 11
  • x64 데스크톱 환경
  • .NET 8 Desktop Runtime 또는 SDK
  • 네이티브 실행 파일 링크에는 NASM/GCC 도구 체인이 필요

SKKOA Studio는 내장 컴파일러를 우선 사용하며, 필요한 도구 체인은 앱의 Tools 메뉴에서 설치/복구할 수 있습니다.
